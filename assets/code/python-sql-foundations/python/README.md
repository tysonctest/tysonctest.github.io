# Python Foundations Code Samples

This folder contains cleaned public copies of Python programming assignments from Business Analytic Fundamentals / DSCI 405. The scripts emphasize introductory programming concepts: user input, arithmetic, conditionals, loops, lists, functions, basic statistics, and code comments.

These files are included as a technical-foundations artifact rather than as production software. Many scripts are intentionally interactive because they were written for introductory programming practice.
